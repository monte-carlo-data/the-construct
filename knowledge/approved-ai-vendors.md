# Approved AI Vendors

This file lists the AI vendors, models, and AI-enabled SaaS features your organization has reviewed
and approved. Oracle reads it (from Git, so the list is reviewable and diff-able) when deciding
whether a detected AI tool, API key, or integration is sanctioned — anything not present is flagged
as potential shadow AI.

---

## How to use

Add a row for each approved vendor or model. Keep the *Scope* column honest — "approved for internal
docs" is not "approved for customer data" — because Oracle and Morpheus phrase their outreach from it.
